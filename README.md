# Felix Blog 

Este é um projeto de blog pessoal desenvolvido com [Next.js](https://nextjs.org/) e integrado à [API do Notion](https://developers.notion.com/) para gerenciar e exibir postagens. Com essa abordagem, as postagens do blog podem ser editadas diretamente no Notion, simplificando a administração do conteúdo.

## Funcionalidades

- Listagem de postagens com título, resumo e data de publicação.
- Visualização de postagens individuais com conteúdo dinâmico vindo do Notion.
- Atualização automática das postagens com integração à API do Notion.

## Tecnologias Utilizadas

- **Next.js**: Framework React para construção de aplicações web com renderização no servidor.
- **Notion API**: Usada para gerenciar as postagens e armazenar o conteúdo do blog.
- **TypeScript**: Para garantir tipagem e segurança no código (opcional).

## Pré-requisitos

- Conta no Notion com o conteúdo do blog organizado (banco de dados de posts).
- Chave de API do Notion para acessar o banco de dados.
- Node.js e npm/yarn instalados.
